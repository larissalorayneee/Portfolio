PORTFÓLIO - LARISSA LORAYNE

ESTRUTURA
- index.html: página inicial
- sobre.html: apresentação pessoal
- skills.html: habilidades
- projetos.html: projetos
- mapa.html: Mapa-múndi Explorer
- calculadora-salario.html: calculadora de valor da hora
- qr-code.html: gerador de QR Code
- timeline.html: formação, cursos e experiência
- contato.html: contato e currículo em PDF

TESTAR LOCALMENTE
1. Extraia a pasta Portfolio.
2. Abra a pasta em um editor como VS Code.
3. Inicie um servidor local (por exemplo, Live Server).
4. Abra index.html pelo servidor local.
5. Teste os links do menu, formulários e projetos.

OBSERVAÇÕES
- O Mapa-múndi Explorer consulta a API pública REST Countries e precisa de conexão com a internet.
- O currículo técnico em PDF está em assets/curriculo-larissa.pdf.
- A calculadora estima o mês usando 22 dias úteis. A escala real pode variar.
- O formulário de contato utiliza o endpoint Formspree que já estava configurado no projeto.
